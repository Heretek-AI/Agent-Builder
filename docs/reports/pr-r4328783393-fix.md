## Summary

Partially-addressed finding completed. Commit `a0ea0e7` already fixed the
`exposure:hidden + toolExposure:{only hidden}` sub-case (`tools = allowedList`
even when empty) but left the `exposure:hidden` with **no `toolExposure` map**
sub-case open: the guard sat inside `if (isPlainObject(srv.toolExposure))`,
so `tools` stayed `['*']`. That is exactly the compiler-produced deny-only
shape (`buildPiOutputs` in `src/core/compiler.js:411-427` sets
`entry.exposure = 'hidden'` and omits `toolExposure` when empty), so a
compile → import round-trip of `.pi/mcp.<slug>.json` escalated deny-only to
full wildcard allow.

Fix adds a minimal fail-closed `else if` branch: hidden with no
`toolExposure` map imports as explicit `tools: []` (deny). Wildcard defaults
for non-hidden preserved; wildcard key `'*'` + `hidden` entries remain
excluded from the allow list. No other behavior changed.
